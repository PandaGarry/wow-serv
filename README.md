# Admin Tools RU — GM-панель для World of Warcraft 3.3.5

Модульный игровой аддон: панель GM-команд с кнопкой на миникарте, вертикальными
вкладками, избранным и поиском. Заточен под сборку
**WoW Repack NPCBots AzerothCore + Eluna + Extras + Custom Races [335a Solo/LAN]**,
работает и на чистом AzerothCore / TrinityCore 3.3.5. Интерфейс — на русском.

```text
/admin            открыть/закрыть панель          (или ЛКМ по кнопке на миникарте)
/admin <команда>  выполнить команду               (например /admin tele stormwind)
/ath              справка          /atbench  замер скорости панели
/atecho           эхо команд       /atreset  сбросить все настройки
```

**Что нового в 5.2**

* новая вкладка **«Интерфейс»**: 5 тем оформления (Голубая, Изумрудная,
  Аметистовая, Янтарная, Розовая), 4 размера окна, 4 положения окна,
  кнопка на миникарте — показ/скрытие и угол на окружности;
* **подсветка строк** — полоса под строкой кнопок и полей при наведении
  (можно выключить);
* **переключатели чтения**: подсказки, поля фильтра, подсветка — всё
  в одном месте, применяется мгновенно;
* значки ▲/▼ в панели истории заменены на «Вверх»/«Вниз» — в шрифтах 3.3.5
  стрелок и треугольников может не быть, и вместо них появлялись «?»;
* автотест проверяет, что в текстах аддона нет символов вне набора
  ASCII + кириллица + «» – — … (то есть в игре не будет «квадратов»).

**5.1.1 — исправление:** панель не открывалась по `/admin`, в игре была ошибка
`Main.lua:129`. Причина: у `FontString` (подписи) вызывался `SetScript`, которого
у текстовых объектов в WoW нет — ошибка обрывала `Main.lua`, поэтому не создавались
ни слэш-команды, ни кнопка на миникарте (клиент на `/admin` отвечал «ищите в /помощь»).
Теперь счётчик истории обновляется по событию, а тесты ловят такой класс ошибок
и в статике, и в прогоне.

**Что нового в 5.1**

* современный тёмный интерфейс: свои текстуры скина, акцентный цвет, вертикальные вкладки;
* 2 новые вкладки — **«Мир»** (объекты, `.go`, `.lookup`) и **«Модули»** (Extras твоего репака);
* вкладка **«Боты»** переписана под полный мануал NPCBots (движение, дистанции, спеки, фракции, приказы);
* **избранное** (Shift+ЛКМ), **фильтр-поиск**, **ПКМ → команда в поле ввода**,
  **Shift+клик по нику в чате** → имя в поле ввода;
* цвет кнопки = уровень доступа (зелёный/жёлтый/красный), заблокированное — серое;
* настройка размера шрифта **без подмены файла шрифта** — русский текст не ломается никогда;
* `/atbench` — встроенный замер производительности панели.

Проверка: **2610 автопроверок**, 0 падений, плюс аудит всех 71 команды по ядру и модулям.

## 1. Установка

```bash
./tools/build.sh          # соберёт dist/AdminToolsRU.zip
./tools/check.sh          # прогонит автотесты (нужен Node.js, один раз npm install)
```

Распакуй `AdminToolsRU.zip` (или папку `dist/AdminToolsRU`) в `<WoW>/Interface/AddOns/`:

```text
Interface/AddOns/AdminToolsRU/
├── AdminToolsRU.toc     порядок загрузки
├── Bindings.xml         горячая клавиша (необязателен)
├── Core.lua             ядро: скин, виджеты, вкладки, избранное, фильтр
├── Data.lua             ► данные твоего сервера (телепорты, NPC, модули)
├── Main.lua             шапка, панель команд, миникарта, события
├── Tab_*.lua            вкладки (12 штук)
└── skin/*.tga           текстуры оформления
```

В игре: **Esc → Модификации → включить «Admin Tools RU»** (и поставь галочку
**«Загружать устаревшие аддоны»** — для 3.3.5 это обязательно), либо «Перезагрузить интерфейс».

**Требования:** клиент 3.3.5a (Interface 30300) и GM-права на аккаунте. Аддон не лезет
в БД напрямую: он отправляет обычные GM-команды, а сервер решает, что разрешено.

## 2. Вкладки

| Вкладка | Содержимое |
|---|---|
| **Мир** | `.go`, `.gps`, объекты (`.gobject`), спавн и правка NPC, `.lookup` по всему |
| **Телепорт** | столицы (с предупреждением о вражеских), свободный `.tele`, сохранение точек, фильтр городов |
| **Путешествие** | подземелья, рейды, места кача — меню по дополнениям |
| **Боты** | NPCBots целиком: движение, дистанции, поиск/спавн, спеки, фракции, приказы, удаление |
| **NPC** | кастомные NPC сервера + стандартные торговцы, фильтр, удаление/перемещение |
| **Модули** | команды и NPC-услуги твоего репака (`.hirebot`, `.npcarena`, `.bank`, `.buff`, `.ga` …) |
| **Себя** | GM-режим, читы, ауры, КД, скорость и размер |
| **Персонаж** | уровни, таланты, изучение, деньги, предметы, раса/фракция/имя (Custom Races) |
| **Группа** | действия с целью, призыв, кик, инфо об игроке |
| **Сервер** | инфо, игроки и доступ (кик/мут/баны), обслуживание, анонсы, аккаунты |
| **Интерфейс** | 5 тем оформления, размер и положение окна, кнопка миникарты (угол/скрытие), подсветка строк, подсказки, фильтр |
| **Настройки** | видимость вкладок, эхо, блокировка по уровню, масштаб, шрифт, сброс позиций |
| **Свои** | свои кнопки: ЛКМ — выполнить, ПКМ — изменить / переместить / удалить |

Опасные действия (выключение/рестарт, удаление NPC и бота, бан, телепорт в столицу врага)
спрашивают подтверждение. Ненужные вкладки скрываются галочками в «Настройках».

## 3. Как работать быстро

| Действие | Результат |
|---|---|
| **ЛКМ** по кнопке | выполнить команду |
| **ПКМ** по кнопке | команда попадает в поле ввода — можно поправить и выполнить |
| **Shift+ЛКМ** по кнопке | добавить/убрать в «Избранное» (шапка панели) |
| **Shift+клик по нику в чате** | имя добавляется в поле ввода (для `.kick`, `.summon`, `.ban`) |
| **▲ / ▼** в панели команд | история последних 30 команд |
| поле «поиск…» | мгновенный фильтр кнопок на большой вкладке |
| горячая клавиша | Esc → Назначение клавиш → категория «Admin Tools RU» |
| вкладка «Интерфейс» | темы, размер и положение окна, кнопка миникарты, чтение интерфейса |
| `/atbench` | замер: переключение вкладок, высоты, число кнопок, память аддона |

### Оформление

Вкладка **«Интерфейс»** — всё внешнее в одном месте:

* **5 тем**: Голубая, Изумрудная, Аметистовая, Янтарная, Розовая. Смена темы —
  мгновенная перекраска (текстуры белые и тонируются в рантайме), сохраняется
  между сессиями;
* **размер окна**: Компактный 780x560 · Обычный 880x620 · Широкий 1000x660 ·
  Максимум 1120x700;
* **положение окна**: центр, слева, справа, сверху — или перетащи мышью за шапку;
* **кнопка на миникарте**: скрыть/показать, поставить под любым углом
  (180, 135, 90, 45, 0, 315, 270, 225) или вернуть в угол по умолчанию;
* **чтение интерфейса**: подсветка строк при наведении, всплывающие подсказки,
  поля фильтра — по отдельности.

Макеты без запуска игры: `python3 tools/mockup.py` →
`tools/preview/panel-mockup.png`, `panel-interface.png`, `themes-preview.png`
(все пять тем рядом).

## 4. Настройка под свой сервер

Почти всё серверно-зависимое лежит в одном файле — **`AdminToolsRU/Data.lua`**:

* `AT.DATA.cities` — столицы для «Телепорта»;
* `AT.DATA.dungeons`, `raids`, `grindAlliance`, `grindHorde` — «Путешествие»;
* `AT.DATA.npcGroups` — NPC вкладки «NPC»; `AT.DATA.bagItemId` — ID «сумки»;
* `AT.DATA.repackNpcSpawns`, `repackUtilities`, `repackConfig` — вкладка «Модули»;
* `AT.DATA.botClasses`, `botHeroClasses`, `botFactions` — вкладка «Боты».

Если телепорт не срабатывает — имя не совпало с колонкой `name` таблицы `game_tele`.
Готовые запросы: **[tools/sql/teleports.sql](tools/sql/teleports.sql)**.

## 6. Разработка

```text
AdminToolsRU/        сам аддон (копируется в Interface/AddOns)
tools/check.sh       автотесты (заглушка WoW API + Fengari, 2610 проверок)
tools/build.sh       сборка dist/AdminToolsRU.zip
tools/gen_textures.py  генерация текстур скина (TGA) из кода
tools/mockup.py      макет панели в PNG (по реальным координатам кода)
tools/sql/           SQL-помощник по телепортам
```

Автотесты поднимают аддон в настоящем Lua-интерпретаторе на заглушке API 3.3.5:
грузят все файлы в порядке `.toc`, эмулируют `ADDON_LOADED`/`PLAYER_LOGIN`,
прокликивают **327 кнопок**, проверяют попапы, меню, избранное, фильтр, шрифты,
темы, размеры окна, уровни доступа, подсветку строк. Плюс четыре отдельных аудита:

| Аудит | Что ловит |
|---|---|
| команды | любую команду, которой нет в AzerothCore/NPCBots/модулях сборки |
| текстуры | ссылку на `skin/*.tga`, которого нет на диске |
| регионы | фреймовые методы (`SetScript` и др.) у FontString/Texture — обрывало загрузку |
| символы | знаки, которых нет в шрифтах 3.3.5 (■, →, № и т.п. → «?» в игре) |

```bash
cd tools && npm install    # один раз
cd .. && ./tools/check.sh  # → 2610 пройдено, 0 провалено
```

### Как добавить вкладку

```lua
-- AdminToolsRU/Tab_MyTab.lua
local p = AT.RegisterTab("Моя вкладка")   -- кнопка в колонке + прокручиваемая страница

local y = AT.MakeSection(p, "Раздел", -2)
y = AT.FlowButtons(p, {
    { "Кнопка",   ".gps", AT.BTN_W, 1, "Подсказка" },      -- 1 = модератор
    { "Для админа", ".die", AT.BTN_W, 3, "Только админ" },  -- 3 = администратор
}, y)
AT.AttachFilter(p, "поиск…")   -- необязательно: фильтр по кнопкам
```

Добавь файл в `AdminToolsRU.toc` **до** `Main.lua` — и всё.

## 7. Частые вопросы

**Панель не открывается, `/admin` не найден** — в чате должна быть красная ошибка
Lua с именем файла и строкой. Напиши мне её текст. Проверь, что установлена версия
**5.1.1 и выше** (`/ath` показывает версию; в 5.1.0 и раньше была ошибка
`Main.lua:129`, из-за которой слэш-команды не регистрировались). Если ошибка
повторится — пришли её текст и номер строки, исправлю.

**Аддон не появился в списке** — путь должен быть `Interface/AddOns/AdminToolsRU/AdminToolsRU.toc`
(без двойной вложенности), клиент 3.3.5, галочка «Загружать устаревшие аддоны».

**Квадраты вместо русского текста** — это шрифты клиента, лечится папкой `Fonts/`
с кириллическим шрифтом в 4 копиях (`FRIZQT_.TTF`, `ARIALN.TTF`, `MORPHEUS.TTF`,
`skurri.ttf`). Подробно: [docs/UI-STRATEGY-RU.md](docs/UI-STRATEGY-RU.md), раздел 2.
Наша панель шрифт не подменяет, поэтому у неё этой проблемы нет.

**Команда не выполняется** — сервер её отклонил (нет прав) либо команда не поддерживается
модулем. Включи `/atecho`, чтобы видеть, что именно отправляет панель.

**Панель не влезает в экран** — «Настройки» → «Масштаб окна» (`-`/`+`) либо сброс позиции окна.

**Мешает кнопка на миникарте** — перетащи мышью (позиция сохраняется), скрой в
«Настройках» или назначь горячую клавишу и убери кнопку совсем.

**Хочу всё сбросить** — `/atreset`.
