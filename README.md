# Admin Tools RU — GM-панель для World of Warcraft 3.3.5

Модульный игровой аддон: панель GM-команд с кнопкой на миникарте, вкладками по
задачам и своими кнопками. Работает на серверах **AzerothCore / TrinityCore 3.3.5**
(и форках), интерфейс — полностью на русском.

> **Статус:** v5.0.0 — полностью переработанная и протестированная версия.
> Исходники, которые лежали в репозитории до этого, были повреждены и не
> загружались в игре — подробности в
> [docs/CORRUPTION-REPORT-RU.md](docs/CORRUPTION-REPORT-RU.md).

```
/админ  →  открыть панель        ЛКМ по кнопке на миникарте — панель
                                  ПКМ по кнопке — сразу вкладка «Телепорт»
```

---

## 1. Установка

**Быстрый способ:**

```bash
./tools/build.sh
```

Скрипт соберёт `dist/AdminToolsRU.zip`. Распакуй его (или папку `dist/AdminToolsRU`)
в `<WoW>/Interface/AddOns/` так, чтобы получилось:

```
World of Warcraft/
└── Interface/
    └── AddOns/
        └── AdminToolsRU/
            ├── AdminToolsRU.toc
            ├── Bindings.xml
            ├── Core.lua
            ├── Data.lua
            ├── Main.lua
            └── Tab_*.lua
```

**Вручную:** скопируй папку `AdminToolsRU` из репозитория в `Interface/AddOns/`.

Затем в игре: экран выбора персонажа → «Аддоны» → включить **Admin Tools RU**,
или нажать «Перезагрузить интерфейс» (если персонаж уже в мире).

**Требования:** клиент 3.3.5a (Interface 30300) и **GM-права на аккаунте**.
Аддон не лезет в базу данных напрямую — он отправляет обычные GM-команды в чат,
а сервер сам решает, что тебе можно. С уровнем доступа ниже `3` часть команд
сервер отклонит — это нормально и не является ошибкой аддона.

## 2. Команды

| Команда | Что делает |
|---|---|
| `/admin` или `/adt` | открыть/закрыть панель |
| `/admin <команда>` | выполнить одну команду, напр. `/admin tele stormwind` |
| `/ath` или `/adminhelp` | справка по аддону в чат |
| `/atecho` | включить/выключить вывод выполненных команд в чат |
| `/atreset` | сбросить все настройки аддона и перезагрузить интерфейс |

Горячую клавишу для панели можно назначить в игре: **Esc → Назначение клавиш →
категория «Admin Tools RU»**.

## 3. Вкладки

| Вкладка | Что внутри |
|---|---|
| **Телепорт** | столицы Альянса/Орды/нейтральные (с предупреждением о вражеском городе), свободный `.tele`, поиск телепорта, сохранение точки, `.recall`, сброс привязок к подземельям |
| **Путешествие** | выпадающие списки: подземелья и рейды по дополнениям, места кача для Альянса и Орды |
| **Боты** | модуль NPCBots: следовать/стоять/воскресить, дистанция, поиск и спавн бота, присвоить/уволить/удалить, подсказки по классам и спекам |
| **NPC** | быстрый спавн NPC (трансмог, маунты, банкиры, аукционисты и т.д.), спавн по ID, удалить/переместить/инфо о выбранном NPC |
| **Себя** | GM-режим, видимость, полёт, воскрешение, ауры, сброс КД, карта, навыки, скорость и размер |
| **Персонаж** | уровни, сброс талантов и заклинаний, изучение всего, починка, деньги, сумки, добавление предметов и наборов |
| **Группа** | действия с целью (убить/воскресить/заморозить), призыв группы, явиться/призвать/кик игрока, инфо об игроке |
| **Сервер** | инфо, GPS, аккаунт, кто онлайн, сохранение, анонсы, MOTD, выключение и рестарт с подтверждением |
| **Настройки** | видимость вкладок, эхо команд, свой уровень доступа, масштаб окна, сброс позиций |
| **Свои** | свои кнопки с любыми командами: ЛКМ — выполнить, ПКМ — изменить / переместить / удалить |

Ненужные вкладки можно **скрыть галочками** в «Настройках» (они не удаляются,
всегда можно вернуть) или закомментировать строку в `AdminToolsRU.toc`.

Все опасные действия (выключение сервера, удаление NPC, удаление бота, телепорт
в столицу вражеской фракции) спрашивают подтверждение.

## 4. Настройка под свой сервер

Почти всё, что зависит от конкретного сервера, лежит в одном файле —
**`AdminToolsRU/Data.lua`**:

* `AT.DATA.cities` — столицы для вкладки «Телепорт»;
* `AT.DATA.dungeons`, `AT.DATA.raids`, `AT.DATA.grindAlliance`, `AT.DATA.grindHorde` — списки «Путешествия»;
* `AT.DATA.npcGroups` — NPC для вкладки «NPC» (кастомные NPC твоих модулей и стандартные торговцы);
* `AT.DATA.bagItemId` — ID предмета, который выдаётся кнопкой «Сумка x1/x4»;
* `AT.DATA.npcbotClasses`, `AT.DATA.npcbotSpeccs` — подсказки по ботам.

### Если телепорт не срабатывает

Команда `.tele <имя>` ищет совпадение по колонке `name` таблицы `game_tele`.
Названия в разных сборках отличаются, поэтому проверь свою базу запросами из
**[tools/sql/teleports.sql](tools/sql/teleports.sql)** и поправь `Data.lua`.

Где имени телепорта нет — используй координаты: `.go xyz X Y Z MAP`
(так уже сделано для Наксрамаса, Цитадели Ледяной Короны и Логова Крыла Тьмы).

## 5. Разработка

```
AdminToolsRU/          сам аддон (эту папку копируют в Interface/AddOns)
├── Core.lua           ядро: окно, тема, виджеты, реестр вкладок, прокрутка
├── Data.lua           данные сервера (правь под себя)
├── Main.lua           панель команд, миникарта, слэш-команды, события
├── Tab_*.lua          вкладки (каждая сама себя регистрирует)
├── Bindings.xml       горячая клавиша (необязателен)
└── AdminToolsRU.toc   порядок загрузки

tools/
├── check.sh           запустить автотесты
├── build.sh           собрать dist/AdminToolsRU.zip
├── sql/teleports.sql  запросы к game_tele
└── test/              стенд: заглушка WoW API + 1300+ проверок
```

### Автотесты

Аддон можно проверить **без запуска игры**: `tools/test/wow_stub.lua` эмулирует
API 3.3.5 (виджеты, геометрию, события, попапы, меню), аддон загружается в
настоящий Lua-интерпретатор (Fengari), после чего прогоняется набор проверок:
все 10 вкладок регистрируются, прокликиваются все кнопки, проверяются команды,
подтверждения, меню, история, настройки и данные.

```bash
cd tools && npm install     # один раз, нужен Node.js и интернет
cd .. && ./tools/check.sh
```

Ожидаемый результат: `1349 пройдено, 0 провалено`.

### Как добавить вкладку

```lua
-- AdminToolsRU/Tab_MyTab.lua
local p = AT.RegisterTab("Моя вкладка")   -- создаёт кнопку и прокручиваемую страницу

local y = AT.MakeSection(p, "Раздел", -2)
y = AT.FlowButtons(p, {
    { "Кнопка",  ".gps", AT.BTN_W, 1, "Подсказка кнопки" },
    { "В своём", ".die", AT.BTN_W, 3, "Только для админа" },
}, y)
```

Добавь файл в `AdminToolsRU.toc` **до** `Main.lua` — и всё. Помощники ядра:
`MakeButton`, `MakeLabel`, `MakeEdit`, `MakeSection`, `FlowButtons`, `FormRow`,
`FormRow2`, `TeleSection`, `BuildMenu`, `ConfirmCmd`, `RunCmd`.

## 6. Частые вопросы

**Аддон не появился в списке** — проверь, что путь выглядит как
`Interface/AddOns/AdminToolsRU/AdminToolsRU.toc` (не двойная вложенность папок),
и что клиент 3.3.5.

**Команда не выполняется** — скорее всего сервер её отклонил (нет прав или
команда отключена). Включи `/atecho`, чтобы видеть, что именно отправляет аддон.

**Панель не влезает в экран** — «Настройки» → «Масштаб окна» (кнопки `-` и `+`),
либо сбрось позицию окна там же.

**Хочу другую кнопку на миникарте** — просто перетащи её мышью, позиция
сохранится. Вернуть на место: «Настройки» → «Позиция кнопки миникарты».

**Сбросить всё** — `/atreset`.
