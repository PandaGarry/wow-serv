# Русификация сервера (AzerothCore + NPCBots + Eluna)

Работа идёт по шагам. На каждом шаге вы что-то делаете у себя и присылаете результат,
а я готовлю следующую порцию перевода.

## Где берётся английский текст

| Что в игре | Где хранится | Как переводим |
|---|---|---|
| Меню и фразы ботов, описания классов | `acore_world.npc_text` (ID 70000–71000) | `npc_text_locale`, готовый перевод + дописываем недостающее |
| Имена NPC, квесты, предметы, диалоги | `acore_world.*_template` | таблицы `*_locale` (ruRU) |
| Системные сообщения, ответы на команды | `acore_world.acore_string` | колонка `locale_ruRU` |
| Кастомные NPC (трансмог, энчантер, буфер…) | Eluna `.lua` скрипты или C++ модули | правим тексты в скриптах |
| Интерфейс игры | клиент | у вас ruRU, уже на русском |

Сервер выдаёт русский текст только клиенту ruRU. Английский показывается там,
где русского перевода в базе нет.

---

## Шаг 0. Резервная копия (обязательно)

1. Запустите сервер БД репака (обычно MySQL стартует вместе с репаком или через `Start_MySQL.bat`).
2. Откройте **HeidiSQL** (или другой клиент MySQL). Параметры по умолчанию у репаков:
   хост `127.0.0.1`, порт `3306`, пользователь `root`, пароль `root` (если не подходит, загляните
   в `worldserver.conf`, строку `WorldDatabaseInfo`).
3. Правый клик по базе **acore_world** → «Экспорт базы данных как SQL» → сохраните файл.
   Если что-то пойдёт не так, базу можно восстановить из этого файла.

## Шаг 1. Диагностика (ничего не меняет)

1. Выберите слева базу **acore_world**, откройте вкладку «Запрос».
2. Вставьте содержимое `sql/00_diagnostika.sql` и нажмите **F9**.
3. Пришлите мне результат: скриншот или просто скопируйте таблицу в чат.

По ней будет видно, чего в базе не хватает.

## Шаг 2. Перевод ботов (готов)

1. **Остановите worldserver.**
2. В базе **acore_world** выполните `sql/01_npcbots_npc_text_locale_ruRU.sql`
   (HeidiSQL: «Файл» → «Загрузить SQL-файл» → F9).
3. Запустите worldserver и поговорите с ботом.

Это официальный русский перевод от автора NPCBots (trickerer).

## Шаг 3. Выгрузка того, что осталось непереведённым

1. Выполните `sql/99_eksport_neperevedennogo.sql` в **acore_world**. Будет 4 результата (A, B, C, D).
2. Каждый результат сохраните в CSV: правый клик по таблице результата → «Экспорт строк» →
   формат CSV, кодировка UTF-8.
3. Загрузите файлы в репозиторий в папку `ru-translation/export/`
   (на GitHub: «Add file» → «Upload files»). Можно и просто прислать мне в чат.

По этим файлам я сделаю SQL с переводом.

## Шаг 4. Скрипты Eluna и кастомные NPC

Загрузите в репозиторий в папку `ru-translation/server-files/`:

- папку **`lua_scripts`** из папки сервера (там, где `worldserver.exe`), это скрипты Eluna;
- папку **`configs/modules`** (или файлы `*.conf.dist` модулей), чтобы я понял, какие модули стоят;
- **`worldserver.conf`** (перед отправкой сотрите пароли в строках `...DatabaseInfo`).

Если папок нет или не можете их найти, пришлите скриншот содержимого папки сервера.
