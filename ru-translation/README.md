# Русификация сервера (AzerothCore + NPCBots + Eluna)

Работа идёт по шагам. На каждом шаге вы что-то делаете у себя и присылаете результат,
а я готовлю следующую порцию перевода.

## Где берётся английский текст

| Что в игре | Где хранится | Как переводим |
|---|---|---|
| Меню и фразы ботов, описания классов | `acore_world.npc_text` (ID 70000–71000) | `npc_text_locale`, готовый перевод + дописываем недостающее |
| Имена NPC, квесты, предметы, диалоги | `acore_world.*_template` | таблицы `*_locale` (ruRU) |
| Системные сообщения, ответы на команды | `acore_world.acore_string` | колонка `locale_ruRU` |
| Кастомные NPC (трансмог, энчантер, буфер…) | Eluna `.lua` скрипты или C++ модули | правим тексты в скриптах |
| Интерфейс игры | клиент | у вас ruRU, уже на русском |

Сервер выдаёт русский текст только клиенту ruRU. Английский показывается там,
где русского перевода в базе нет.

---

## Шаг 0. Резервная копия (обязательно)

1. Запустите сервер БД репака (обычно MySQL стартует вместе с репаком или через `Start_MySQL.bat`).
2. Откройте **HeidiSQL** (или другой клиент MySQL). Параметры по умолчанию у репаков:
   хост `127.0.0.1`, порт `3306`, пользователь `root`, пароль `root` (если не подходит, загляните
   в `worldserver.conf`, строку `WorldDatabaseInfo`).
3. Правый клик по базе **acore_world** → «Экспорт базы данных как SQL» → сохраните файл.
   Если что-то пойдёт не так, базу можно восстановить из этого файла.

## Шаг 1. Диагностика (ничего не меняет)

1. Выберите слева базу **acore_world**, откройте вкладку «Запрос».
2. Вставьте содержимое `sql/00_diagnostika.sql` и нажмите **F9**.
3. Пришлите мне результат: скриншот или просто скопируйте таблицу в чат.

По ней будет видно, чего в базе не хватает.

## Шаг 2. Применить перевод ✅ готово

Всё, что было в ваших выгрузках (1.csv–4.csv), переведено:

| Файл | Что переводит | Строк |
|---|---|---|
| `sql/01_npcbots_npc_text_locale_ruRU.sql` | официальный перевод ботов (автор NPCBots) | 377 |
| `sql/02_npcbots_npc_text_dop.sql` | новые фразы и меню ботов (банк снаряжения, порталы, владельцы…) | 50 |
| `sql/03_suschestva_imena.sql` | подписи ботов («Воин (бот)»), питомцы, кастомные NPC | 391 |
| `sql/04_menyu_npc.sql` | пункты меню NPC, телепортёр (Portal Master) | 588 |
| `sql/05_soobscheniya_servera.sql` | системные сообщения и ответы на GM-команды | 1193 |
| **`sql/RUSIFIKACIYA_VSE.sql`** | **всё вышеперечисленное одним файлом** | 2599 |

**Как применить:**
1. Сделайте бэкап (шаг 0), если ещё не сделали.
2. **Остановите worldserver.**
3. В HeidiSQL выберите базу **acore_world** → «Файл» → «Загрузить SQL-файл» →
   `sql/RUSIFIKACIYA_VSE.sql` → **F9**.
   Файл большой, выполнение займёт несколько секунд. Если HeidiSQL спросит, открыть файл
   или выполнить его напрямую, выберите «Выполнить» (Run).
4. Запустите worldserver и проверьте: поговорите с ботом, с Portal Master, введите `.help`.

Файлы можно применять повторно: перед вставкой старые русские строки удаляются.
Если применяете файлы по отдельности, соблюдайте порядок: 01 → 02 → 03 → 04 → 05
(01 очищает все переводы ботов 70000–71000 перед вставкой).

Личные имена ботов (Llane, Thran…) оставлены как есть. Переведены подписи под именем,
питомцы и служебные NPC.

## Шаг 3. Скрипты Eluna и кастомные NPC (следующий этап)

Часть текстов кастомных NPC (трансмог, энчантер, буфер, Beastmaster и др.) может быть
зашита в скриптах, а не в базе. Загрузите в репозиторий в папку `ru-translation/server-files/`:

- папку **`lua_scripts`** из папки сервера (там, где `worldserver.exe`);
- папку **`configs/modules`** (или файлы `*.conf.dist` модулей);
- **`worldserver.conf`** (перед отправкой сотрите пароли в строках `...DatabaseInfo`).

## Для разработчика: как пересобрать SQL

```
cd ru-translation
python3 tools/gen.py
```

Переводы лежат в `tools/tr_*.py`, выгрузки — в `export/`. Генератор проверяет, что
плейсхолдеры (`{}`, `%u`, `|cff…|r`, `$B` и т.д.) в переводе совпадают с оригиналом.
