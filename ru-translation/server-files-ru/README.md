# Переведённые файлы сервера (Eluna + конфиги модулей)

Создано скриптами `ru-translation/tools/lua_tr.py` и `conf_tr.py` из файлов в `ru-translation/server-files/`.

## Как установить
1. Остановите worldserver.
2. **Сделайте резервную копию** своей папки `lua_scripts` и папки `configs/modules`.
3. Скопируйте содержимое `server-files-ru/lua_scripts/` в папку `lua_scripts` сервера с заменой файлов.
4. Скопируйте файлы из `server-files-ru/configs/modules/` в папку `configs/modules` сервера с заменой
   (заменяются только `npc_buffer`, `npc_enchanter`, `random_enchants`, остальные настройки в них не изменены).
5. Запустите worldserver.

## Что переведено
- Зачаровыватель (Enchanter.lua): меню и все названия чар.
- Боевой пропуск (battlepass): NPC, команды `.bp` / `.bpadmin`, все сообщения.
- AppearanceBuddy (трансмогрификация): серверные сообщения и ошибки.
- Магазин (Store_System, был на испанском), банк, ремонт, сброс подземелий, баффы.
- Хардкор, множитель добычи `.ga`, объявления о входе/выходе, мировой чат (`[Мир]`).
- Фразы NPC-баффера и зачаровывателя, сообщение RandomEnchants.

Не переводились: сообщения в консоль сервера (print/лог), служебные имена и ключи.
