## 2. Чистка («марафет»)

Удалено из пака (всё это есть в исходном `AddOns.rar`, при необходимости восстанавливается):

* `.DS_Store`, файл-«ярлык» `ru-addons.ru - `;
* **23 папки `Blizzard_*`** — внутри каждой лежал один 257-байтный `*.pub`
  (двоичный мусор загрузчика, ни одного файла аддона). В `Blizzard_Calendar/`
  при этом лежали **старые копии** BonusScanner и GearScore (GearScore 3.1.15
  против 3.1.17 в отдельной папке) — тоже удалены, чтобы клиент не грузил дубли;
* `Mangosbot/.git` (вложенный репозиторий, ~2.6 МБ) и `Mangosbot/src/`
  — исходники картинок `.xcf`, `Strategies.xlsx`, **`lua53.exe` и `lua53.dll`**
  (Windows-бинарники, 410 КБ) — в игре не нужны;
* `QuestHelper/.svn` и `QuestHelper/libs/ChatThrottleLib/.svn`;
* `Quartz/locale/Babelfish.lua` — внешний скрипт разработчика (запускается
  интерпретатором Lua вне игры, в `locale.xml` не подключён);
* пустые каталоги (`Bagnon_GuildBank/localization` и др.).

`AdminToolsRU` из архива (5.1.1) заменён на актуальный **5.3.0** из корня репозитория.

## 4. Русификация

### BattlePass (серверный модуль боевого пропуска) — был целиком английский

* `locale/ruRU.lua` — словарь (~60 строк): заголовки, состояния наград,
  подсказки, сообщения в чат, команда `/bp info`;
* `BattlePass.lua` — строки берутся через `L()`/`F()` с английским фолбэком,
  статические подписи из `BattlePass.xml` («Battle Pass», «Progression», «Sync»,
  «Claim All», «Info») подставляются при загрузке;
* строки протокола (`sync`, `hide`, `info`) и имена функций сервера **не** переведены —
  это идентификаторы обмена с сервером.

### AppearanceBuddy (трансмогрификация) — был целиком английский, 15 700 строк кода

* `localization.lua` + `locale/ruRU.lua` — 174 строки словаря и функция
  `ABL("English")`, возвращающая русский текст или исходную строку;
* переведено 160 мест: вкладки, кнопки, фильтры, подсказки, статусы
  («Применить», «Забрать всё», «Фильтр: всё», «Стоимость: …», «Открыто предметов: 4/8»…);
* переведены **только подписи**: имена якорей, шрифтов, а также подклассы предметов
  («Sword», «Cloth»), которые уходят в серверные запросы AIO, остаются английскими —
  на экран они выводятся через `ABL()`, а в API уходит исходное значение.

### OmniCC / OmniCC_Config — добавлена русская локализация

`localization/localization.ru.lua` в обеих папках (около 60 строк: названия разделов,
«Чёрный список», подсказки про ГКД и формат ММ:СС) + регистрация в `localization.xml`.

### Mangosbot, AIO_Client — точечно

* Mangosbot: русские названия привязок клавиш в меню «Назначение клавиш»,
  видимые подписи панели («Нажмите!», «Панель управления ботами», «Отладка»);
* AIO_Client: сообщения `/aio help`, сброс кэша, переключение отладки.

## 5. Что осталось и что стоит знать

1. **GearScore** — русского нет: в аддоне жёстко зашиты английские подписи окна и
   настроек, готового механизма локализации нет (в locale-файлах только расы и классы).
   Это отдельная задача: ~70 мест вывода. Скажите — сделаю следующим этапом.
2. **Mangosbot** — это панель ботов **MaNGOS/ike3**, а не NPCBots. На вашем репаке
   (AzerothCore + NPCBots) она ничего не делает; в паке оставлена, потому что была
   в архиве. Рекомендую не копировать её в клиент, чтобы не путать ботов.
3. **Шрифты.** Если где-то русский текст превращается в `?` или квадраты — у клиента
   нет кириллицы в стандартных шрифтах. Лечится один раз: создать `<WoW>/Fonts/` и
   положить туда кириллический TTF четырьмя копиями — `FRIZQT_.TTF`, `ARIALN.TTF`,
   `MORPHEUS.TTF`, `skurri.ttf` (подробно в `docs/UI-STRATEGY-RU.md`, §2).
   Именно из-за этого QuestHelper просит шрифты в своей папке `Fonts/`
   (их там нет по замыслу автора — есть только `readme.txt`).
4. **Тяжёлые библиотеки.** Внутри аддонов лежат их собственные копии Ace3, LibQTip,
   LibStub и т. п. Это нормально для 3.3.5 (нет менеджера библиотек), но если хочется
   ужать пак — можно вынести общие библиотеки в отдельные папки; выигрыш ~2–3 МБ.

## 6. Как проверить

```bash
# полный аудит дерева аддонов (toc, синтаксис Lua, XML, мусор, кодировки, русский)
python3 tools/audit_addons.py AddOns            # человекочитаемый отчёт
python3 tools/audit_addons.py AddOns --json /tmp/audit.json

# только синтаксис Lua (Fengari; перед первым запуском: npm install в tools/)
node tools/lua_syntax.js AddOns
```

Аудит проверяет: поля `.toc`, наличие каждого перечисленного файла, регистр имён,
дубликаты, синтаксис всех `.lua`, разбор всех `.xml`, пустые каталоги и мусорные
файлы, кодировки, а также есть ли русский текст (файл локализации, кириллица в коде
или родительский аддон — как у `XPerl_Party` и `Bagnon_Forever`).

Отдельная проверка — **помощники локализации**: если код вызывает `ABL()` или `MBL()`,
функция обязана быть объявлена в аддоне. Такая опечатка проходит проверку синтаксиса
(Lua компилируется), но в игре падает с `attempt to call global 'ABL' (a nil value)`.

Текущий результат: **0 ошибок**, 3 замечания — все три записаны как допустимые
для Lua 5.1 (`invalid escape sequence`) и помечены в отчёте `(5.1-ok)`.

## 7. Установка

```text
1. Скопировать содержимое AddOns/ в <WoW>/Interface/AddOns/
   (то есть в клиенте появятся папки AdminToolsRU, BattlePass, AppearanceBuddy, ...)
2. Удалить Cache/ (клиент перечитает список аддонов)
3. Экран выбора персонажа → «Аддоны»: включить нужные (Mangosbot — см. §5.2)
```

Пак рассчитан на клиент 3.3.5a (интерфейс `30300`), проверен на
«WoW Repack NPCBots AzerothCore + Eluna + Extras + Custom Races [335a Solo/LAN]»,
где серверная часть боевого пропуска уже стоит.
