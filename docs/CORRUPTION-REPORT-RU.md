# Отчёт: почему исходники аддона не работали

Коротко: **аддон, загруженный в репозиторий 22.09.2026, не мог загрузиться в игре
вообще** — часть файлов пришла с повреждённым содержимым. Ниже — что именно было
сломано, как это доказано и что сделано.

---

## 1. Что показала проверка

Файлы в коммите `5436cf4` («Add files via upload») сверил с тем, что лежит в Git:
SHA-1 каждого файла на диске совпал с хешем блоба в репозитории. Это значит, что
повреждение **не** возникло при скачивании или распаковке — файлы пришли такими
изначально.

## 2. Как выглядит повреждение

Из пострадавших мест вырезаны служебные ASCII-символы:
`"` `:` `|` `\` `/` `>` `'` `<` `&`. Кириллица, цифры, скобки, запятые и точки
остались на месте — поэтому «на глаз» файл выглядит почти нормально.

Примеры из `Core.lua` (слева — что должно быть, справа — что лежит в репозитории):

```lua
if type(cmd) ~= "string" then          →  if type(cmd) ~= string then
cmd:sub(1, 1) ~= "."                   →  cmdsub(1, 1) ~= .
if #cmd > 255 then                     →  if #cmd  255 then
DEFAULT_CHAT_FRAME:AddMessage(...)     →  DEFAULT_CHAT_FRAMEAddMessage(...)
".tele " .. teleName                   →  .tele  .. teleName
b:SetSize(w or AT.BTN_W, AT.BTN_H)     →  bSetSize(w or AT.BTN_W, AT.BTN_H)
text = "Выполнить команду:\n\n%s"      →  text = Выполнить командуnn%s
```

Пример из `Tab_NPC.lua`:

```lua
local p = AT.RegisterTab("NPC")                          →  local p = AT.RegisterTab(NPC)
{ "Трансмог (190010)", ".npc add 190010", AT.BTN_W, 1,   →  { Трансмог (190010), .npc add 190010, AT.BTN_W, 1,
  "NPC для трансмогрификации" },                              NPC для трансмогрификации },
AT.MakeSection(p, "Стандартные NPC (Альянс / Орда)")     →  AT.MakeSection(p, Стандартные NPC (Альянс  Орда))
```

## 3. Почему аддон не мог заработать

1. **`Core.lua` не компилируется.** В Lua ошибка синтаксиса в файле означает, что
   файл не выполняется целиком — значит `AT` не создаётся вообще.
2. **Дальше всё сыпется каскадом.** Каждый `Tab_*.lua` начинается с
   `AT.RegisterTab(...)`, а `AT` — `nil`. `Main.lua` тоже обращается к `AT`.
   Итог: аддон не показывается в игре, в чат сыпятся ошибки Lua.
3. **Даже в «целых» файлах были свои баги**, которые проявились бы после починки
   синтаксиса:
   * `StaticPopupDialogs[ADMINTOOLS_CONFIRM]` — `ADMINTOOLS_CONFIRM` не определено,
     то есть ключ `nil`. Запись в таблицу по `nil`-ключу — это ошибка
     «table index is nil» в момент загрузки `Core.lua`.
   * `Main.lua` создавал главное окно (`AT.frame`), но загружался **последним**:
     вкладки к тому моменту уже пытались создавать кнопки с `parent = nil`.
   * `AT.RunCmd` вызывал `GameTooltipSetOwner`, `DEFAULT_CHAT_FRAMEAddMessage` и
     `cmdsub(...)` — таких функций в API нет.
   * в `AT.MakeButton` в подсказке собиралась строка с `nil`-полями уровня доступа.

## 4. Что сделано

Аддон **пересобран заново** в версии 5.0.0 с сохранением всего замысла:

* все вкладки, команды, ID NPC, тексты и структура (`Телепорт`, `Путешествие`,
  `Боты`, `NPC`, `Себя`, `Персонаж`, `Группа`, `Сервер`, `Настройки`, `Свои`);
* исправлены перечисленные выше баги API 3.3.5;
* серверные данные (телепорты, NPC) вынесены в один файл `AdminToolsRU/Data.lua`,
  чтобы их можно было править без правки логики;
* добавлены автотесты, которые прогоняют аддон в настоящем Lua-интерпретаторе на
  заглушке WoW API: 1349 проверок, включая прокликивание всех кнопок.

Повреждённые файлы **не потеряны** — они остались в истории Git:

```bash
git show 5436cf4:Core.lua       # исходный (повреждённый) Core.lua
git show 5436cf4:Tab_NPC.lua    # исходный (повреждённый) Tab_NPC.lua
```

Старый `README-RU.txt` перенесён в `docs/README-RU-legacy.txt`.

## 5. Как не повторить

Судя по набору пропавших символов (`"` `:` `|` `\` `/` `>` — то, что обычно
экранируется в HTML/разметке/ссылках), файлы прошли через какой-то промежуточный
этап «очистки»: копирование через чат, веб-форму, генератор кода, «форматтер» или
антивирус/DLP. Чтобы этого избежать:

1. Правь аддон в нормальном редакторе (VS Code, Notepad++, Sublime) и коммить
   файлы напрямую через git — без промежуточного копирования через браузер.
2. Перед установкой в игру запускай проверку:

   ```bash
   ./tools/check.sh          # синтаксис + 1349 проверок поведения
   ```

3. Если правишь командой в терминале/чате — не используй инструменты, которые
   «чистят» текст (санитайзеры, HTML-экранирование, markdown-рендер).
4. После любых правок сверяй: `git diff` не должен показывать изменения в
   кавычках и двоеточиях на строках, которых ты не касался.
