# Совместимость: твой список аддонов × Admin Tools × UI-паки

Разбор по каждому аддону из твоего списка: с чем он пересекается, конфликтует ли
с нашей панелью и что делать.

---

## 1. Главный вывод

**Admin Tools RU ни с одним аддоном из твоего списка не конфликтует.** Причина
конструктивная: панель не переопределяет ни один фрейм Blizzard. Она только добавляет
свои объекты и не трогает чужие:

| Что делает панель | Риск конфликта |
|---|---|
| Своё окно `AdminToolsRUFrame` (отдельный фрейм) | нет — ни один аддон его не знает |
| Кнопка на `Minimap` (перетаскиваемая, скрываемая) | только **визуальный** — много кнопок на миникарте |
| Свой тултип через `GameTooltip` | нет — все так делают, тултип стакается корректно |
| Хук `SetItemRef` (только чтение, `hooksecurefunc`) | нет — хук не меняет оригинальное поведение |
| Отправка команд в чат (`SendChatMessage`) | нет — это обычный чат |
| Свой шрифт | **нет — файл шрифта не подменяется, берётся клиентский** |

А вот **UI-паки (включая FenUI) конфликтуют практически со всем** — потому что они
переопределяют те же фреймы, что и остальные аддоны из списка. Ниже видно, где именно.

## 3. Важно про Mangosbot в твоей сборке

`Mangosbot` (celguar/mangosbot-addon) — это аддон для **mangosbot (ike3)** из мира
**MaNGOS/CMaNGOS**. У тебя сборка на **AzerothCore + NPCBots** — это **другая система
ботов** и, что важнее, **другой протокол**: Mangosbot общается с сервером через
специальный канал (`#a` префикс, `BOT\t`), которого в NPCBots нет.

Что это значит на практике:

* **держать его можно** (не мешает), но командовать своих NPCBots через него не выйдет;
* если он будет писать в чат `/bot` и ждать ответа — ты увидишь пустые окна;
* **управление твоими ботами делает наш аддон** — вкладка «Боты», команды `.npcbot ...`
  (сверено с официальным мануалом NPCBots, 37 команд);
* если хочется панели-«роутера» как в Mangosbot (кнопки: атака, фоллоу, пассив, лут) —
  это можно добавить кнопками в нашем избранном или на вкладку «Боты» за 5 минут. Скажи — сделаю.

## 4. Кнопки на миникарте: единственная реальная «конфликтная точка»

У тебя много аддонов с кнопками на миникарте: Recount, AtlasLoot, QuestHelper, BattlePass,
возможно AIO и AppearanceBuddy. Это не конфликт кода, а **визуальная свалка**.

Что у нас уже сделано:

* кнопку панели можно **перетащить** — позиция сохраняется;
* её можно **скрыть** в «Настройках» (галочка «Показывать кнопку на миникарте»);
* она **не раздувается** (28×28, текстура `MiniMap-TrackingBorder` совместима с любым клиентом);
* «Настройки» → «Позиция кнопки миникарты» — вернуть на место одной кнопкой.

Что предлагаю: поставить круговую раскладку кнопок (`SexyMap` или `DetachedMiniMapButton`)
либо назначить горячую клавишу панели (Esc → Назначение клавиш → «Admin Tools RU») и
убрать её с миникарты совсем.

## 5. Шрифты — вторая «конфликтная точка» (и главная причина «квадратов»)

Эта беда задевает **все** твои аддоны с текстом (MSBT, OmniCC, QuestHelper, GearScore,
DrDamage, BattlePass), а не только UI-паки. Механика и лечение — в
[UI-STRATEGY-RU.md](UI-STRATEGY-RU.md), раздел 2. Коротко:

1. создать `<WoW>/Fonts/`;
2. положить туда шрифт **с кириллицей** в 4 копиях: `FRIZQT_.TTF`, `ARIALN.TTF`,
   `MORPHEUS.TTF`, `skurri.ttf`.

После этого любой аддон и любой пак, который жёстко просит `Fonts\FRIZQT__.TTF`,
получит русский текст корректно. Наша панель этой процедуры **не требует** — она
не подменяет шрифт.

### Проект `patch-Z.mpq` (AIO_Client)

`AIO_Client` = `Rochet2/AIO`: серверная часть + клиентский `patch-Z.mpq` с
дополнительными текстурами/интерфейсом. Поэтому:

* `patch-Z.mpq` кладут в `<WoW>/Data/`, и после этого **обязательно чистят `Cache`**;
* `patch-Z` может переопределять часть Blizzard-файлов интерфейса → **UI-пак и `patch-Z`
  одновременно — плохая идея** (они подменяют одни и те же файлы, победит тот, кто
  загрузится позже);
* с нашей панелью конфликта нет: мы читаем только свои файлы из своей папки.

## 6. Порядок проверки, если что-то «странно выглядит»

1. `/atbench` — если панель тормозит, увидишь цифры, а не догадки.
2. Отключить аддоны по половине (стандартная бисекция) — найти виновника.
3. Включить **«Загружать устаревшие аддоны»** — для 3.3.5 это обязательно.
4. Проверить `Cache` — при смене `patch-*.mpq` он должен быть очищен.
5. Если ломается текст (квадраты/вопросы) — это шрифты, см. пункт 5. Не аддоны.
6. Если ломаются панели/фреймы после установки UI-пака — это пак переопределил фреймы;
   убирай по одному из пары (например, X-Perl **или** фреймы пака).
