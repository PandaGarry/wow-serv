Admin Tools RU v2.2 — русская панель GM-команд
================================================

Установка:
1. Папка AdminToolsRU в Interface/AddOns/
2. Внутри: AdminToolsRU.toc и AdminToolsRU.lua
3. Включи аддон в меню выбора персонажа.

Использование:
- /admin или /adt — открыть/закрыть окно.
- /admin <команда> — выполнить одну команду.

Вкладки:
- Телепорт — города, поиск, сохранение точек.
- Путешествие — подземелья, рейды, места кача (выпадающие меню).
- Боты — управление NPCBots (следовать, стоять, воскресить).
- Себя — GM-режим, полёт, скорость, ауры.
- Персонаж — уровни, заклинания, предметы, деньги.
- Группа — призыв, воскрешение, кик.
- Призыв — временные NPC (торговцы, банкиры, аукционисты).
- Сервер — инфо, анонсы, выключение.
- Свои — добавление/редактирование своих кнопок (ЛКМ — выполнить, ПКМ — изменить).
